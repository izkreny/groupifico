Groupifico font pairings

Pick a pairing for each column and tune it; each section lines up across both columns. Below each Character set, the dashed lines are letters the styleguide does not show yet: Serbian Cyrillic, set as Serbian so a font's Serbian letterforms apply, then Greek, Bulgarian and the other EU letters. A letter drawn in a different typeface there is a font that lacks it.

Coverage was read from each family's source TTF in the google/fonts repository, letter by letter, not from Google's subset labels: Caprasimo is labelled latin-ext and still lacks Č Ć Đ Ž. "No Greek" fonts cover every Latin-script EU language and Serbian and Bulgarian Cyrillic. Optical size on "auto" follows the font size, the way the browser applies it by default. Your settings are remembered in this browser only.
