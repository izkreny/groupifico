1. The daisyUI tokens, as painted

Hex values are read back from the rendered swatch, so what you see is what the theme paints. "Pair" is the WCAG ratio of the token against the colour it is used with. 4.5:1 clears AA for text, 3:1 clears it for large text and interface chrome.
